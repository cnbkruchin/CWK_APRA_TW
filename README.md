# CWK Championship Planner — APRA International Final 2026

ระบบวางแผนการแข่งขันของทีม **CWK JAEGER ROBOT** (E02 • กลุ่ม E • Field 4)
รายการ **APRA International Final 2026 • SPIKE Remote Soccer – Junior • 14 พ.ย. 2026 (ไต้หวัน)**

แปลงมาจากไฟล์ `source/CWK_APRA_2026_Championship_Plan.xlsx` ทั้ง 6 ชีต และใช้งานได้ 2 แบบ

| รูปแบบ | วิธีใช้ |
|---|---|
| **เว็บสแตนด์อโลน** | ดับเบิลคลิกไฟล์ `index.html` ใช้งานได้ทันทีโดยไม่ต้องติดตั้งหรือต่ออินเทอร์เน็ต (ทั้งแอพอยู่ในไฟล์เดียว) |
| **แอพบนมือถือ (PWA)** | เปิดผ่านลิงก์ GitHub Pages แล้วกด "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอนแอพ เปิดเต็มจอ และใช้ได้แม้ไม่มีเน็ตในสนาม |
| **ออนไลน์ (ลิงก์เดิม)** | ใส่ค่า Firebase ใน `config.js` แล้วทุกเครื่องจะเห็นข้อมูลชุดเดียวกันแบบสด โค้ชแก้ไขได้ ผู้ปกครองดูอย่างเดียว — ดูวิธีตั้งค่าใน **[ONLINE.md](ONLINE.md)** |

## ฟีเจอร์

**หน้าหลัก**
- นับถอยหลังถึงวันแข่ง พอถึงวันงานจะแสดงว่าตอนนี้อยู่ช่วงไหน เหลือกี่นาที และรายการถัดไปคืออะไร
- การ์ดนัดถัดไปของ CWK: คู่แข่ง เวลาไต้หวัน/ไทย สนาม แผน เป้าหมาย บันทึกสเกาท์ และคำเตือนให้รายงานตัว (C5)
- ตารางคะแนนกลุ่ม E แบบสด พร้อมคำตอบว่า "ถ้าชนะ / เสมอ / แพ้ นัดถัดไป จะเป็นอย่างไร"
- ตัวนับใบเหลือง (ครบ 4 ใบ = ตัดสิทธิ์) และความคืบหน้าของเช็กลิสต์

**ตารางเวลา** (ชีต 01)
- 17 รายการ แสดงทั้งเวลาไต้หวันและเวลาไทย ไฮไลต์รายการปัจจุบันและเลื่อนจอไปหารายการนั้นอัตโนมัติ
- ติ๊กว่ารายการไหนเสร็จแล้ว
- **เลื่อนเวลา** ±5/10/15 นาที เมื่อการแข่งล่าช้า: เลื่อนรายการที่เลือกและทุกรายการหลังจากนั้นให้ทั้งหมด รวมถึงเวลาแมตช์ และกด "เลิกทำ" ได้
- แก้ไข เพิ่ม หรือลบรายการได้

**ผลแข่ง** (ชีต 02, 03, 05)
- กรอกสกอร์ด้วยปุ่ม + / − หรือพิมพ์ตัวเลข
- ตารางคะแนนคำนวณอันดับตามกติกา F3–F4 ให้จริง: แต้ม → ผลพบกันเอง → ผลต่างประตู → ประตูได้ (Excel เดิมทำได้แค่ขึ้นคำเตือน) และบอกเหตุผลว่าทีมไหนอยู่เหนือทีมไหนด้วยเกณฑ์ใด
- ถ้าเท่ากันทุกเกณฑ์ จะขึ้นอันดับร่วม (เช่น 2=) พร้อมข้อความ "ปรึกษากรรมการ"
- **วิเคราะห์เส้นทางเข้ารอบ:** คำนวณจากทุกผลที่เป็นไปได้ของนัดที่เหลือ แล้วติดป้าย "เข้ารอบแน่นอน / ตกรอบ / ลุ้น" ให้ทุกทีม
- น็อกเอาต์: เลือกคู่รอบรองฯ ตามที่กรรมการประกาศ (มีปุ่มช่วยใส่คู่แบบแชมป์กลุ่มพบรองแชมป์อีกกลุ่ม ซึ่งต้องกดยืนยันก่อน) ถ้าเสมอจะมีช่องบันทึกต่อเวลา Golden Goal และรอบ 1v1 ผู้ชนะและผู้แพ้จะถูกส่งไปนัดชิงชนะเลิศและชิงที่ 3 อัตโนมัติ

**จับเวลา**
- ค่าตั้งไว้ตามกติกา: รอบกลุ่ม/รองฯ (เตรียม 2 + ครึ่งละ 3 นาที), ชิงที่ 3/ชิงแชมป์ (ครึ่งละ 5 นาที), ต่อเวลา (2+2 นาที) และพัก/ซ่อม (ตั้งเวลาเองได้)
- มีเสียงเตือนที่ 30 วิ, 10 วิ และ 3 วิสุดท้าย เครื่อง Android จะสั่นเมื่อหมดช่วงด้วย และเบราว์เซอร์ที่รองรับจะไม่ให้หน้าจอดับระหว่างจับเวลา ปุ่ม ±10 วิ ไว้ปรับให้ตรงกับนาฬิกากรรมการ
- กระดานสกอร์สดที่บันทึกลงตารางผลทันที พร้อมช่องนับใบเหลือง

**แผน / กติกา** (ชีต 04, 06)
- แผนการเล่น 9 สถานการณ์ เลือกสถานการณ์แล้วดูหน้าที่ของหุ่นตัวที่ 1 และตัวที่ 2 ตัวอักษรใหญ่ อ่านง่ายข้างสนาม
- เช็กลิสต์การซ้อมเสริม 6 แบบ
- ตรวจตามกติกา 19 ข้อ ให้สถานะ ผ่าน / ต้องตรวจ / ไม่ผ่าน (ตัวเลือกเดียวกับใน Excel)
- เช็กลิสต์ Quick check หลังแต่ละนัด และเช็กลิสต์อุปกรณ์/สเปกหุ่น (แก้ไขหรือเพิ่มรายการได้)
- บันทึกสเกาท์คู่แข่งรายทีม โดยบันทึกของคู่แข่งนัดถัดไปจะขึ้นที่หน้าหลักด้วย

**โหมดซ้อมแข่งขัน** (หน้า แผน/กติกา → ซ้อมแข่ง)
- **รูปแบบการซ้อม 7 แบบ:** 6 แบบมาจาก "การซ้อมเสริม" ใน Excel ได้แก่ เต็มเกม 6 นาที, พลิกเกมจาก 0–1, รักษาสกอร์ 1–0, Golden Goal 2 นาที, หุ่นเดี่ยว 1 ต่อ 1 และทนทานครึ่งละ 5 นาที อีกแบบคือ "กำหนดเอง" ที่ตั้งจำนวนครึ่ง เวลา สกอร์เริ่มต้น และแบบยิงก่อนชนะได้
- **เลือกทีมได้ทั้ง 2 ฝ่าย:**
  - ทีมเรา
  - ทีมซ้อมที่เพิ่มเอง เช่น ทีมรุ่นน้อง หรือโรงเรียนที่มาซ้อมด้วย
  - ทีมในรายการ ให้ทีมซ้อมเล่น "จำลอง" คู่แข่งทีมนั้น โดยหน้าจอจะแสดงบันทึกสเกาท์และภาพของทีมนั้นให้ดูประกอบ
- ทุกรูปแบบดึงเป้าหมาย (KPI) และหน้าที่หุ่นตัวที่ 1 / ตัวที่ 2 มาจาก **แผนการเล่น** และแสดง **กติกาที่เกี่ยวข้อง**
- **ระหว่างซ้อม:**
  - นาฬิกาตามกติกา (ใช้ร่วมกับหน้าจับเวลา)
  - ปุ่ม ⚽ ประตู, 🎯 ยิงพลาด, 🟨 ใบเหลือง/ฟาวล์, ⚠ หุ่นค้าง ที่บันทึกช่วงเวลาให้ทุกครั้ง และย้อนเหตุการณ์ล่าสุดได้
  - แบบยิงก่อนชนะจะหยุดเกมให้ทันทีเมื่อมีประตู
- **จบการซ้อม:**
  - ระบบประเมินว่าผ่านเป้าหมายหรือไม่ให้อัตโนมัติ และแก้ได้
  - เขียนบันทึกหลังซ้อมได้
  - ข้อในรายการ "การซ้อมเสริม" ถูกติ๊กให้เอง
- **ประวัติการซ้อม:**
  - สถิติของทีมเรา ได้แก่ ชนะ-เสมอ-แพ้, ประตูได้-เสีย, % ยิงเข้า, ผ่าน KPI, ใบเหลือง และหุ่นค้าง
  - กรองดูตามคู่ซ้อม และดูแยกตามรูปแบบ
  - ส่งออก **.csv** ไปเปิดใน Excel / Google Sheets ได้
- ทางลัด: ปุ่ม **▶ ซ้อม** ข้างการซ้อมเสริมแต่ละข้อ และปุ่ม **ซ้อมสถานการณ์นี้** ในการ์ดแผนการเล่น
- **โหมดออนไลน์:** ประวัติการซ้อมและรายชื่อทีมซ้อมแชร์ให้ทุกเครื่อง ผู้ชมกดซ้อมเล่นในเครื่องได้ แต่บันทึกลงประวัติได้เฉพาะโค้ช

**ภาพ / วิดีโอสเกาท์** (หน้า แผน/กติกา → คู่แข่ง)
- แต่ละทีม (รวมทีมเราเอง) มีปุ่ม **📷 ถ่ายภาพ**, **🎥 ถ่ายวิดีโอ** (เปิดกล้องมือถือทันที) และ **🖼 เลือกไฟล์** (เลือกจากคลังได้ทีละหลายไฟล์)
- ภาพถูกย่อด้านยาวเหลือ 1,600 px ให้ยังเห็นรายละเอียดหุ่นชัด ส่วนวิดีโอเก็บไฟล์จริงพร้อมภาพปกและความยาว
- แตะภาพย่อเพื่อเปิดดูเต็มจอ ปัดซ้าย/ขวาเพื่อเลื่อนดู เขียนคำอธิบายได้ (เช่น "กลไกเตะด้านหน้า") และกดแชร์ส่งเข้า LINE / Google Drive / คลังภาพได้
- ภาพสเกาท์ของคู่แข่งนัดถัดไปจะขึ้นที่หน้าหลักด้วย
- **ดาวน์โหลด .zip** ได้ทั้งหมดหรือทีละทีม ไฟล์แยกโฟลเดอร์ตามทีม พร้อมไฟล์ `บันทึกสเกาท์.txt` (บันทึก ผลที่เจอเรา และคำอธิบายของแต่ละไฟล์) ไว้ใช้พัฒนาทีมภายหลัง
- ไฟล์เก็บในเครื่องด้วย IndexedDB ซึ่งรับไฟล์ขนาดใหญ่ได้ และใช้งานออฟไลน์ได้ ส่วนในโหมดออนไลน์จะแชร์ให้ทุกเครื่อง (ดู [ONLINE.md](ONLINE.md))
- ไฟล์สำรอง .json **ไม่รวม** ภาพ/วิดีโอ ให้ใช้ .zip แทน
- iPhone / iPad: ควร **ติดตั้งเป็นแอพบนหน้าจอโฮม** เพราะ Safari อาจล้างข้อมูลของเว็บที่ไม่ได้เปิดนานกว่า 7 วัน และควรดาวน์โหลด .zip เก็บไว้หลังจบรายการ

**เมนู ⋮ (ตั้งค่า)**
- **คัดลอกสรุปผล** เป็นข้อความพร้อมส่ง LINE ให้ผู้ปกครองและทีม
- **สำรองข้อมูล / นำเข้า** (.json) ไว้ย้ายเครื่องหรือส่งต่อให้โค้ชคนอื่น
- พิมพ์ / บันทึก PDF, เลือกธีมสว่าง/มืด, เปลี่ยนทีมของเรา/วันแข่ง/ชื่อรายการ
- ล้างผลการแข่งขัน หรือคืนค่าเริ่มต้นทั้งหมด (กดเลิกทำได้)

## เปิดใช้เป็นแอพบนมือถือ (GitHub Pages)

ทำครั้งเดียว:

1. เข้า repository บน GitHub → **Settings** → **Pages**
2. ที่ **Build and deployment → Source** เลือก **Deploy from a branch**
3. เลือก branch ที่มีไฟล์นี้ (เช่น `main` หลัง merge หรือ `claude/sleepy-archimedes-sd6u9e`) และโฟลเดอร์ **/ (root)** → **Save**
4. รอประมาณ 1–2 นาที จะได้ลิงก์ `https://cnbkruchin.github.io/CWK_APRA_TW/`

ติดตั้งลงมือถือ:

- **iPhone / iPad:** เปิดลิงก์ใน Safari → ปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม**
- **Android:** เปิดใน Chrome → เมนู ⋮ → **ติดตั้งแอป** (หรือ เพิ่มลงในหน้าจอหลัก)

> ให้เปิดแอพหนึ่งครั้งตอนที่ยังมีอินเทอร์เน็ต (เช่น ที่โรงแรม) เครื่องจะเก็บแอพไว้ ทำให้วันแข่งใช้ได้แม้สัญญาณในสนามไม่ดี

## เรื่องข้อมูล

**โหมดออฟไลน์** (ค่าเริ่มต้น เมื่อ `config.js` ว่าง)
- ผล บันทึก และเช็กลิสต์ เก็บไว้ **ในเครื่องที่ใช้งานเท่านั้น** (localStorage) ไม่ถูกส่งขึ้นเซิร์ฟเวอร์ใด
- แต่ละเครื่องมีข้อมูลแยกกัน ถ้าต้องการให้หลายเครื่องตรงกัน ให้ใช้ **สำรองข้อมูล** แล้ว **นำเข้า** ที่อีกเครื่อง หรือให้คนเดียวเป็นผู้บันทึกผลแล้วส่งสรุปเข้า LINE
- การล้างข้อมูลเบราว์เซอร์หรือใช้โหมดไม่ระบุตัวตนจะทำให้ข้อมูลหาย จึงควรกดสำรองข้อมูลก่อนและหลังวันแข่ง

**โหมดออนไลน์** (เมื่อใส่ค่า Firebase ใน `config.js`)
- ข้อมูลการแข่งอยู่บน Firebase และทุกเครื่องเห็นตรงกันแบบสด แต่ละเครื่องเก็บสำเนาไว้ด้วย จึงเปิดดูได้แม้ไม่มีสัญญาณ
- ทุกเครื่องเริ่มเป็น "ผู้ชม" และใส่รหัสโค้ชเพื่อแก้ไข ไอคอนเมฆ ☁ บนแถบด้านบนบอกสถานะการเชื่อมต่อ
- รายละเอียดทั้งหมดอยู่ใน [ONLINE.md](ONLINE.md)

## โครงสร้างไฟล์

```
index.html            แอพทั้งหมด (HTML + CSS + JS ในไฟล์เดียว ไม่พึ่งไลบรารีภายนอก)
config.js             ตั้งค่าโหมดออนไลน์ (ปล่อยว่าง = ออฟไลน์)
ONLINE.md             คู่มือเปิดโหมดออนไลน์ด้วย Firebase
firebase/             กฎความปลอดภัยของฐานข้อมูล (database.rules.json)
manifest.webmanifest  ข้อมูลสำหรับติดตั้งเป็นแอพ (PWA)
sw.js                 service worker สำหรับใช้งานออฟไลน์
icons/                ไอคอนแอพ
source/               ไฟล์ Excel ต้นฉบับ
```

ข้อมูลตั้งต้น (ทีม ตารางเวลา แมตช์ แผนการเล่น กติกา) อยู่ในฟังก์ชัน `DEFAULTS()` ใน `index.html` ถ้าจะใช้กับรายการแข่งอื่น ให้แก้ข้อมูลในส่วนนี้
